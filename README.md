**Personal Expense Tracker CLI**

A simple, Python-based command-line tool to track daily expenses and visualize spending habits by category.

**Features**
* *Add Expenses:* Log amount, category, and description.
* *Auto-Date:* Automatically records the date of entry.
* *Data Persistence:* Saves all data to expenses.json so you never lose records.
* *Summary View:* Aggregates spending by category (e.g., how much you spent on "Food" vs "Rent").

**Requirements**
* Python 3.6 or higher.
**Installation**
1.  Download expense_tracker.py.
2.  Ensure Python is installed (python --version).

**Usage**
1.  Open your terminal or command prompt.
2.  Navigate to the folder containing the script.
3.  Run the following command:
    bash
    python expense_tracker.py
    
4.  Follow the on-screen menu promp Project Structure

   
* expense_tracker.py: Main application logic.
* expenses.json: Database file.
